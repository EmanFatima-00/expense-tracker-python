# 💰 Expense Tracker - Python

A simple and efficient desktop application to manage daily expenses with a clean graphical user interface.

---

### ✨ Features
- Add new expenses
- View all expenses
- Update and delete expenses
- Data saved automatically in JSON file
- Clean and simple Tkinter GUI

### 🛠️ Tech Stack
- **Python Programming**
- **Tkinter** - For creating GUI
- **JSON** - For storing data

### 🚀 How to Run
1. Clone this repository:
   git clone https://github.com/EmanFatima-00/expense-tracker-python.git

2. Run the Python file:
   python expense_tracker.py
